# 规格：原神覆盖浏览器助手

## 需求

1. **始终置顶覆盖层** — WPF 窗口设置 `Topmost=True`，定位于原神游戏窗口之上。
2. **嵌入 WebView2 浏览器** — 加载 B 站视频页面（`https://www.bilibili.com/video/*`）。
3. **全局热键**（通过 `RegisterHotKey` 捕获，游戏激活状态同样生效）：
   - `5` / `6` — 快进 / 快退（前后跳转 10 秒）。
   - `` ` ``（反引号）— 播放 / 暂停切换。
   - `7` / `8` — 降低 / 增加窗口透明度。
   - `9` — 隐藏 / 恢复窗口。
   - `0` — 书签弹窗（打开一个包含已保存书签的小面板）。
   - `-` — 切换自动跳过对话开关。
4. **首次运行快捷方式** — 在桌面创建以无边框窗口模式启动原神的快捷方式。
5. **透明度控制** — 透明度范围 0.1 – 1.0，步长 0.1。
6. **自动跳过对话** — 启用时每 2 秒注入 JavaScript 查找并关闭 B 站对话/弹窗。
7. **窗口位置调整与大小调整** — 用户可拖动和调整大小，位置在会话间记忆。

## 行为

- 启动时：显示覆盖窗口，加载默认 B 站页面或提示用户粘贴 URL 的空白页。
- 窗口起始透明度 50%，尺寸 480×360 像素，屏幕居中。
- 热键全局生效——无需聚焦覆盖窗口。
- 自动跳过对话：启用时，定时器每 2 秒执行：
  ```js
  document.querySelector('.bili-dialog')?.remove()
  ```
- 书签弹窗：一个列出已保存视频 URL 的子窗口；点击书签导航主 WebView2。

## 验收标准

1. 覆盖窗口在原神上方保持置顶（全屏或无边框窗口模式均生效）。
2. 每个热键触发正确的操作（通过手动测试验证）。
3. 透明度变化立即可见。
4. 自动跳过对话在 B 站对话出现后 1-2 秒内移除。
5. 首次运行在桌面创建无边框快捷方式。
6. 窗口位置和尺寸在下次启动时恢复。
