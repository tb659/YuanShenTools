# 提案：原神覆盖浏览器助手

## 概要

一个 WPF 覆盖层工具，置于原神游戏窗口之上，内嵌 WebView2 浏览器播放 B 站攻略视频。用户通过全局热键控制视频播放（播放/暂停、快进、快退），无需离开游戏。窗口支持可调透明度、显示/隐藏切换以及自动跳过对话注入。

## 动机

原神地图探索/锄大地攻略通常在 B 站观看。在游戏和浏览器之间切换打断操作流畅性。一个始终置顶、可调透明度、热键驱动的嵌入式浏览器无需 Alt+Tab 切换，让攻略始终可见于游戏之上。

## 范围

- WPF 窗口，设置 `Topmost=true`，嵌入 WebView2，可导航至任意 B 站视频 URL。
- 全局热键（通过 `RegisterHotKey` 注册）：播放/暂停、快进、快退、透明度加减、隐藏/显示、书签弹窗。
- 窗口透明度控制（键 7/8）、隐藏/显示（键 9）、书签弹窗（键 0）、自动跳过对话开关（键 -）。
- 首次运行生成原神无边框启动快捷方式。
- 通过 JavaScript 注入实现 B 站自动跳过对话（点击对话元素）。

## 非目标

- 游戏修改、内存编辑，或任何超出窗口定位的原神进程交互。
- 完整功能浏览器（无标签页、无通用浏览地址栏）。
- 多显示器 DPI 适配调优。
- 视频下载或离线缓存。

## 风险

- 目标机器必须安装 WebView2 运行时（Windows 11 内置 / Windows 10 可通过可再发行组件安装）。
- B 站页面 DOM 变化可能导致自动跳过对话选择器失效——JavaScript 选择器需定期更新。
- 全局热键与原神或其他应用冲突——未来版本中用户可自定义按键绑定。
